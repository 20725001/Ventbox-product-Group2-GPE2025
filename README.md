# Ventbox-product-Group2-GPE2025
VENTBOX is an open-source, 8mm surface-mounted ventilation module designed for 1.9L storage containers. It provides automated environmental control using standard, readily available parts (XIAO MCU, SHT40 sensor, and Sunon UB5U3-700 fan).
